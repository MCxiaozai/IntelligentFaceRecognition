# RFB-640 模型说明

- 输入：RGB 图像，尺寸为 640×480。
- 预处理：等比例缩放，空白区域以 127 填充；再按各通道减 127、乘以 1/127 归一化。
- 输出：`out0` 为背景类和人脸类置信度，`out1` 为归一化的左上角、右下角坐标。
- 后处理：模型图中已经包含先验框解码；程序只进行置信度筛选和非极大值抑制，不应再次生成先验框或解码坐标。
- 原始画面：摄像头输出保持 640×360；检测框会从补边后的模型坐标反映射回原图。
- 文件：`RFB-640.param` 与 `RFB-640.bin` 必须同时保留在此目录。

模型由项目 `models/rfb640/version-RFB-640.onnx` 转换得到，转换工具为 PNNX；该 ONNX 模型来自 Ultra-Light-Fast-Generic-Face-Detector-1MB 项目。
